# Jabatan dan Akses Operasional

Satu akun dapat memiliki beberapa jabatan. Super Admin mengatur jabatan; perubahan dicatat pada audit trail.

| Jabatan | Tanggung jawab utama |
|---|---|
| Super Admin | Akun, jabatan, konfigurasi, audit, dan akses darurat |
| Ketua DKM | Pengawasan, laporan, konten, dan rilis website |
| Sekretaris | Program, agenda, dokumen, dan rilis website |
| Bendahara | Pencatatan dan publikasi keuangan DKM |
| Media & Humas | Artikel, foto, publikasi, dan rilis website |
| Kepala TPQ | Operasional dan keuangan TPQ |
| Pengampu TPQ | Kegiatan operasional TPQ sesuai data yang diizinkan |
| Pembaca | Akses baca terbatas |

Jabatan Super Admin tidak dapat diberikan dari panel biasa untuk mencegah eskalasi akses tidak sengaja.
